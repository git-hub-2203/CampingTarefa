# Projeto: Mini E-commerce de Produtos Digitais

## Descrição do Trabalho

Este projeto foi desenvolvido como avaliação final da disciplina **Desenvolvimento Web I**. O objetivo era criar um site estático de um e-commerce fictício para venda de produtos digitais (e-books, softwares e cursos online). O foco principal foi aplicar os fundamentos do front-end: estruturação semântica com HTML5, estilização responsiva com CSS3 e interatividade básica com JavaScript (Vanilla). O site contém uma página inicial com catálogo de produtos, uma página de detalhes do produto e um carrinho de compras simples, com funcionalidade de adicionar/remover itens via `localStorage`.
